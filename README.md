# NEXUS v1.0 — Exploración de realidades

## Descripción
NEXUS es un proyecto desarrollado en C# para la materia de Programación II. Es una aventura ambientada en el año 2297, donde un cadete explora una realidad desconocida e investiga una anomalía.

## Objetivo
Aplicar los conceptos de programación orientada a objetos mediante clases, objetos, atributos, métodos, constructores, encapsulamiento y herencia.

## Tecnologías
- C#
- Visual Studio Community
- Git y GitHub
- .NET

## Características
- Exploración de zonas.
- Sistema de vida, energía y experiencia.
- Inventario y uso de objetos.
- Personajes, robots y enemigos.
- Misiones y objetivos.

## Cómo ejecutar
1. Descargar o clonar el repositorio.
2. Abrir el archivo `.csproj` en Visual Studio.
3. Comprobar que está instalado el SDK de .NET necesario.
4. Compilar el proyecto.
5. Ejecutarlo desde Visual Studio.

## Documentación
En la carpeta `docs/` se incluirá el manual técnico, los diagramas y la guía de estudio para el examen del Hito 3.

## Propósito académico
Este proyecto permite estudiar y aplicar los fundamentos de Programación II y comprender el funcionamiento de un programa desarrollado con C#.
